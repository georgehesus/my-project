# Cube Protocol — прототип (шаг 1.1: лазы и люки-ирисы)

Игра в духе «Куба»: блуждание по огромному кубу из комнат, переходы через люки,
номера комнат `XX YY ZZ SS`, которые игрок расшифровывает сам.

**Шаг 1.1**: вид от первого лица, комнаты 8 м в стиле референса, между комнатами —
лазы-тоннели (присесть и ползти), вертикальные шахты с лестницей, люки-«ирисы»
(квадрат с крестом из четырёх полос, полосы разъезжаются по диагоналям в стену),
авто-закрытие люка после перехода.

## Запуск

1. Установить **Godot 4.3+** (Forward+).
2. Открыть `project.godot` (Import → выбрать файл).
3. F5 — старт со сцены `scenes/Main.tscn`.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| мышь | обзор |
| E | открыть люк (дальше открывается сам при подходе) |
| C | присесть (в лазе присед включается автоматически) |
| W/S у стены с лестницей / в шахте | лезть вверх/вниз |
| Shift | бег |
| Space | прыжок (в приседе — ниже) |
| Esc | отпустить мышь (клик — захватить обратно) |

## Как устроен переход между комнатами

1. Подошёл к люку (или навёл + E) — полосы люка разъезжаются, за ним виден лаз.
2. Горизонтальный лаз: порог 35 см, внутри потолок 1.3 м → присед и ползание
   (зона лаза форсит присед). Вертикальная шахта: лезть по перекладинам (W/S),
   вниз можно просто прыгнуть в открытый напольный люк.
3. Дополз/долез до соседней комнаты — в момент пересечения границы она становится
   текущей (без телепортов, позиция непрерывна).
4. Отошёл/спрыгнул — выходной люк закрывается сам (~0.8 с), следом закрывается
   входной, и старая комната вместе с лазом выгружается из памяти.

## Загрузка мира

Одновременно в памяти: **текущая комната + одно соединение** (лаз + соседняя
комната). Соединение создаётся при открытии люка и уничтожается, когда оба люка
закрыты и игрок не в лазе. Комната = данные (`RoomData`), геометрия строится
процедурно при загрузке.

## Архитектура (соответствие дизайну)

| Пункт дизайна | Где |
|---|---|
| Комната = данные, не объект | `RoomData.gd`, генерация в `CubeWorld.room_at()` |
| Номер = домашние координаты + SS | `RoomData.label()`, `CubeWorld.ss_for()` |
| `Map[x,y,z] = roomId` | `CubeWorld._cache` (пока тождественное отображение) |
| Грузим только текущую комнату (+1 соединение) | `Main._ensure_conn() / _free_conn()` |
| Простые хвосты безопасны | `CubeWorld.is_prime()`, `RoomData.is_safe_tail()` (ловушек ещё нет) |
| Циклы сдвигов куба | **шаг 2** — место: `CubeWorld` (обновление только Map) |
| Подсказки через окружение | **шаг 3** (трупы, записки, кровь, свет, звук) |

## Геометрия и константы

| Что | Значение | Где |
|---|---|---|
| Ребро комнаты | 8 м (`HALF = 4`) | `Room.HALF` |
| Проём люка | 1.3 × 1.3 м | `Room.OPEN` |
| Длина лаза | 3 м | `Room.TUNNEL_LEN` |
| Шаг сетки комнат | 11 м (`2*HALF + TUNNEL_LEN`) | `Room.STEP` |
| Высота люка боковой стены | 0.35 м над полом | `Room.HATCH_Y` |
| Смещение люков пола/потолка и лестницы | к стене −Z | `Room.WALL_OFF` |
| Размер куба | 26³ | `CubeWorld.CUBE_SIZE` |
| Старт | (13, 13, 13) | `Main.START_COORDS` |

## Прототипные решения

- Люки боковых стен расположены внизу (порог 35 см) — чтобы в лаз можно было
  войти в приседе, без акробатики на высоту 4 м. Люки пола/потолка смещены к
  стене −Z, там же настенная лестница до потолочного люка.
- Люки открываются сами при подходе (< 1.6 м) и закрываются сами, когда игрок
  отошёл (> 2.4 м) или после перехода (0.8 с). E — открыть заранее/издалека.
- Двери-ирисы и стены лазов закрывают проём коллайдером только в закрытом
  состоянии; открытый проём физически проходим.
- Отладочная строка «КОМНАТА xx yy zz ss» слева сверху: убрать — удалить вызов
  `hud.set_room(...)` в `Player._physics_process`.

## Дорожная карта

- **Шаг 2 — движение куба:** цепочки циклов (12/20/16 сдвигов: повороты вперёд +
  те же назад), обновление только `Map`, сдвиги раз в 1–2 мин, момент
  выравнивания + пауза, гул/вибрация перед сдвигом.
- **Шаг 3 — опасность:** ловушки в непростых комнатах (50% мгновенная смерть /
  50% переживаемая), враг-человек в простых комнатах.
- **Шаг 4 — подсказки мира:** трупы, кровь, записки, следы, свет и звук люков,
  «поведение пыли» перед сдвигом; никаких компасов и объяснений.
- **Шаг 5 — цель:** комната-выход, условие победы, петля сеанса.
- **Полировка:** анимации пролезания/спрыгивания, звуки куба и ирисов,
  комната-«мост», сейвы/seed для детерминированных циклов.
